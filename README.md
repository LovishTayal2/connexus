# 🌟 **CONNEXUS - Influencer-Collaborator Interaction Platform** 🎭  
This platform is designed to facilitate seamless interactions between influencers and collaborators. It provides a user-friendly interface where users can connect, collaborate on projects, and manage their data efficiently.

🚀 Features  
✅ User Interface: Built using HTML, CSS, and Bootstrap for a responsive and visually appealing design.  
✅ Dynamic Features: Uses AngularJS & jQuery for real-time validations and interactive elements.  
✅ Backend Services: Developed with Node.js to manage user data efficiently.  
✅ Database: SQL is used for structured data storage and fast retrieval.  
✅ Security: Client-side & server-side validations ensure a secure platform. 🔒  
✅ Admin Panel: An admin dashboard 🛠️ for managing influencers & collaborators effectively.  

Installation
1️⃣ Clone the repository:
```bash
git clone "https://github.com/LovishTayal2/connexus.git"
```
2️⃣ Install dependencies:
```bash
npm install
```
3️⃣ Run the backend server:
```bash
node server.js
```
4️⃣ Open the frontend in a browser:
```bash
open index.html
```
🛠️ Technologies Used  
🎨 Frontend: HTML, CSS, Bootstrap, AngularJS, jQuery  
💾 Backend: Node.js, SQL
